# Heartless Horizon Death Sound

Replaces the default Minecraft death sound with the **Heartless Horizon SMP** death sound.

**Minecraft version:** 1.21.11  
**Requires:** Fabric Loader 0.19+ & Fabric API

## Commands

| Command | Description |
|---|---|
| `/deathsound volume <0-100>` | Set death sound volume (0 = silent, 100 = full) |
| `/deathsound volume` | Show current volume |
